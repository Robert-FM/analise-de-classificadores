Análise de Classificadores
# Stack usada 
Python, Pandas, Numpy, Matplotlib, Jupyter Notebook, Scikit-learn.
# Descrição breve 
Projeto de análise exploratória do datset "adult income"e comparação de modelos de
IA através de análise estatística.
# Objetivo do projeto 
Realizar EDA do dataset e comparar os modelos Decision Tree,Random Forest,
SVM, LVQ e KNN para prever a renda de um individuo.
# Resultado técnico 
O Random Forest apresentou a melhor performance para prever a variável income 
no dataset adult.csv, sobretudo diante do desbalanceamento da amostra. Ele se destacou em Recall, F1 
e AUC, mostrando robustez e consistência. O MLP surge como alternativa próxima, indicado quando a 
Precisão for prioridade junto ao Recall.
